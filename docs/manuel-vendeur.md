# Manuel Vendeur - CafThé

## 1. Connexion dashboard
- Ouvrir `/dashboard`.
- Saisir email + mot de passe vendeur/admin.
- Session active 30 minutes max d'inactivité.

## 2. Produits (CRUD)
- Onglet `Produits`.
- Créer un produit via formulaire.
- Modifier via bouton `Éditer`.
- Désactiver un produit (suppression logique, historique conservé).

## 3. Ventes magasin
- Onglet `Ventes magasin`.
- Ajouter produits + quantités.
- Vérifier total HT / TVA / TTC.
- Enregistrer la vente: stock mis à jour automatiquement.

## 4. Commandes en ligne
- Onglet `Commandes web`.
- Changer le statut: En attente -> En préparation -> Expédiée -> Livrée.

## 5. Clients
- Onglet `Clients`.
- Créer un client.
- Exporter CSV / Excel selon besoin.

## 6. Profil
- Modifier nom/email.
- Changer mot de passe (ancien mot de passe requis).

## 7. Admin uniquement
- Onglet `Comptes vendeurs`.
- Créer, activer, désactiver des comptes vendeurs.
